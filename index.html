Outline no CSS (contornos)

Outline

O que é: o outline em CSS especifica um contorno externo a um elemento, que fica ao lado de fora da sua borda, e tem o principal objetivo de destacar o elemento.

Diferença outline e border: enquanto o border ocupa espaço e é desenhado na caixa do elemento, o outline não ocupa espaço na página, apenas aparece visivelmente, sendo desenhado por cima dos elementos.

Elemento estilizado outline
  • Outline style

    A propriedade CSS outline-style especifica o estilo do contorno. Ela é obrigatória para que um elemento possua contorno, sem ela o navegador não desenha contorno nenhum. Os contornos podem ter 12 estilos diferentes:

    Nenhum

    Não especifica contorno, comportamento padrão

    div { outline-style: none; } Elemento estilizado

    Escondido

    Especifica um contorno escondido

    div { outline-style: hidden; } Elemento estilizado

    Pontilhado

    Especifica um contorno com pontos/bolinhas

    div { outline-style: dotted; } Elemento estilizado

    Tracejado

    Especifica um contorno com traços/linhas seccionadas

    div { outline-style: dashed; } Elemento estilizado

    Sólido

    Especifica um contorno sólido, uma linha de uma cor apenas

    div { outline-style: solid; } Elemento estilizado

    Dobrado

    Especifica um contorno com duas linhas

    div { outline-style: double; } Elemento estilizado

    Sulco

    Especifica um contorno 3D em sulco (lado de fora mais alto)

    div { outline-style: groove; } Elemento estilizado

    Cume

    Especifica um contorno 3D em cume (lado de dentro mais alto)

    div { outline-style: ridge; } Elemento estilizado

    Para dentro

    Especifica um contorno 3D como se fosse um botão pressionado

    div { outline-style: inset; } Elemento estilizado

    Para fora

    Especifica um contorno 3D como se fosse um botão ainda não pressionado

    div { outline-style: outset; } Elemento estilizado

    Inicial

    Retorna a propriedade a seu comportamento padrão (como se fosse um elemento não estilizado)

    div { outline-style: initial; } Elemento estilizado

    Herdado

    Herda o valor da propriedade pai

    div { outline-style: inherit; } Elemento estilizado
    Outline color

    A propriedade CSS outline-color especifica a cor do contorno. Pode ser por meio de uma cor padrão do CSS (como red e blue) ou alguma outra referência de cor (como RGB rgb(244, 0, 0) e hexadecimal #808000).

    div { outline-color: red; } Elemento estilizado

    div { outline-color: #0000FF; } Elemento estilizado

    div { outline-color: rgb(50, 255, 50); } Elemento
    Outline width

    A propriedade CSS outline-width especifica o tamanho do contorno. É possível utilizar três referências de tamanho com nome ou então especificar um tamanho específico:

    Fino

    Especifica uma linha fina

    div { outline-width: thin; } Elemento estilizado

    Médio

    Especifica uma linha de tamanho médio (entre fino e grosso)

    div { outline-width: medium; } Elemento estilizado

    Grosso

    Especifica uma linha grossa

    div { outline-width: thick; } Elemento estilizado

    Tamanho específico

    Especifica um tamanho personalizado para o contorno

    div { outline-width: 9px; } Elemento estilizado
    Outline offset

    A propriedade CSS outline-offset especifica o distanciamento (ou desvio) que o contorno terá do elemento.

    Valores positivos

    Afastam o contorno do elemento

    div { outline-offset: 6px; } Elemento estilizado

    Valor nulo

    Mantém o contorno "colado" no elemento, comportamento padrão

    div { outline-offset: 0px; } Elemento estilizado

    Valor negativo

    Atrai o contorno para o elemento, entrando dentro dele

    div { outline-offset: -6px; } Elemento estilizado
Shorthand (forma curta)

Todo este código aqui:

					div {
					  outline-style: solid;
					  outline-color: #2F9E41;
					  outline-width: 5px;
					}

Pode ser escrito de forma abreviada como:

div { outline: 3px solid #2F9E41; }

Elemento estilizado

Importante notar que o outline-offset não consegue ser escrito dentro da forma abreviada acima, então sempre tem que ser declarado fora:

					div {
					  outline: 3px solid #2F9E41;
					  outline-offset: 10px;
					}
